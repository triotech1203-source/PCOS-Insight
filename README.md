# PCOS Insight

### Multi-class PCOS Subtype Classification using Multimodal Fusion of Clinical Biomarkers and Ultrasound Features with Explainable AI

## 🚀 Live Demo

[*Click here to explore PCOS Insight*](https://pcos-insight-cl3ut7r4xfmjxptgxpwxo4.streamlit.app/)

## Features

- Clinical PCOS subtype classification using XGBoost.
- Ultrasound image classification using CNN.
- SHAP-based explainability for clinical predictions.
- AI-generated clinical and ultrasound advisories using Groq.

## Technologies Used

- Python
- Streamlit
- XGBoost
- TensorFlow / Keras
- SHAP
- Groq API
- Hugging Face

## Models

- XGBoost clinical classification model.
- CNN ultrasound classification model hosted on Hugging Face.

## Disclaimer

This application is developed for research and educational purposes only. It is not intended to provide medical diagnosis or treatment.
